# RoomSync landing page

The marketing page for [RoomSync](https://roomsync-nine.vercel.app): a full-screen video
hero with octagonal "cut-corner" buttons and staggered fade-up animations. Every button
leads into the RoomSync app, its API docs or the source code.

Built with Vite, React, TypeScript, Tailwind CSS v3 and lucide-react.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Deployed on Vercel with `landing` as the root directory.
